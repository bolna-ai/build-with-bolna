Echo is a mobile app where the user speaks their problem (“my kitchen tap is leaking”).  Bolna voice agents then do the calling:
Understand the request and find nearby providers. Bolna agent call several providers in parallel to get time and rate quotes and it will present the quotes for the user to confirm.
Call the chosen provider back to book.
